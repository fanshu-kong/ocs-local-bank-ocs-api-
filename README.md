# ocs-local-bank-ocs-api-
OCS题库配置自动答题
它解决什么问题

网课脚本要自动答题，通常得依赖第三方题库服务，这类服务要么收费，要么不稳定，而且会把题目上传到别人的服务器。这个项目让你在本地自建一个：题目数据、AI 密钥都只留在自己机器上。

怎么工作

OCS 脚本 → POST /search → 本地题库模糊匹配
                          ├─ 命中 → 立即返回（毫秒级，零成本）
                          └─ 未命中 → 调用 AI → 答案写回题库
匹配使用 Sørensen–Dice 二元组相似度，并对待匹配文本做归一化：去掉标点、空格、题号、题型前缀和 LaTeX 公式标记，所以题干格式有细微差异也能命中。

几个比较实用的设计

限流保护：AI 请求串行排队 + 最小间隔 + 429 退避重试 + 全局冷却，避免免费额度被速率限制打断
备用模型：主模型超时自动切换（推理模型偶发卡死时很关键）
动态配置生成：/ocs-config 按你实际访问的 IP 生成配置，换电脑换网络都不用改
隐私边界：密钥只存本地 config.json，管理接口仅允许本机调用，局域网设备访问返回 403
技术栈

Node.js 18+ / 原生 http 模块 / 无第三方依赖 / 原生 WebComponent 之外的纯 HTML+JS 配置页。

适合谁

有一定动手能力、想自己掌控题目数据、不想为搜题服务付费的人。需要能跑起 Node，或者用提供的脚本打包成便携版。
